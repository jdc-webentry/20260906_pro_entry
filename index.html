/** * JDC プロ競技会 申込フォーム用 Google Apps Script * 2026 後期中部日本ダンス選手権（令和8年9月6日） * * このスクリプトは「プロ名簿」スプレッドシートに紐付けて使います。 * ① 選手名簿の検索（doGet） … リーダー登録番号を受け取り、該当の1件だけを返す * ② 申込内容の蓄積（doPost） … 「申込」シートへ1行追記する * 名簿シートは非公開のままで、一覧は外部に出ません。 */ // 名簿タブの名前（この名前のタブを名簿として読みます。新しい名簿ファイルでも名前を合わせるだけで動きます） var ROSTER_SHEET_NAME = '2026年度プロ申込'; // 予備：タブ名で見つからない場合に使うシートID（URLの gid=）。不要なら 0 のままで可 var ROSTER_GID = 1976930737; // 申込を蓄積するタブ名（無ければ自動作成） var ENTRY_SHEET_NAME = '申込'; var ENTRY_HEADERS = [ '申込日時', '登録番号(L)', '登録番号(P)', 'リーダー', 'リーダーかな', 'パートナー', 'パートナーかな', 'リーダー所属教室', 'パートナー所属教室', '住所', '電話番号', '出場区分', '合計金額', 'メール', '振込日', '振込人名', '振込金額', '支局', 'リーダー所属団体', 'パートナー所属団体' ]; function json_(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function getRosterSheet_() { var ss = SpreadsheetApp.getActiveSpreadsheet(); var byName = ss.getSheetByName(ROSTER_SHEET_NAME); if (byName) return byName; var sheets = ss.getSheets(); for (var i = 0; i < sheets.length; i++) { if (sheets[i].getSheetId() === ROSTER_GID) return sheets[i]; } return null; } function getEntrySheet_() { var ss = SpreadsheetApp.getActiveSpreadsheet(); var sh = ss.getSheetByName(ENTRY_SHEET_NAME); if (!sh) { sh = ss.insertSheet(ENTRY_SHEET_NAME); sh.getRange(1, 1, 1, ENTRY_HEADERS.length).setValues([ENTRY_HEADERS]); sh.setFrozenRows(1); } else { // 既存の「申込」シートには、R列=支局／S・T列=所属団体の見出しを追加 if (sh.getRange(1, 18).getValue() !== '支局') sh.getRange(1, 18).setValue('支局'); if (sh.getRange(1, 19).getValue() !== 'リーダー所属団体') sh.getRange(1, 19).setValue('リーダー所属団体'); if (sh.getRange(1, 20).getValue() !== 'パートナー所属団体') sh.getRange(1, 20).setValue('パートナー所属団体'); } return sh; } function s_(v) { return v === null || v === undefined ? '' : String(v).trim(); } // 全角英数字→半角（例：ＪＤＣ→JDC） function half_(v) { return s_(v).replace(/[Ａ-Ｚａ-ｚ０-９]/g, function(c) { return String.fromCharCode(c.charCodeAt(0) - 0xFEE0); }); } /** * 選手名簿の検索 * GET ?leader=4-233 → { result:'ok', found:true, member:{...} } */ function doGet(e) { try { var p = (e && e.parameter) || {}; if (!p.leader) { return json_({ result: 'ok', message: 'GAS is working' }); } var key = s_(p.leader); if (!/^[0-9]-[0-9]{3}$/.test(key)) { return json_({ result: 'ok', found: false }); } var sh = getRosterSheet_(); if (!sh) { return json_({ result: 'error', message: 'roster sheet not found' }); } // 名簿の列構成を自動判定 // ・新形式（2026年度プロ申込Excel）… A1が「キャンセルフラグ」。E:リーダー番号 F:リーダー組織 G:選手名 H:フリガナ // I:パートナー番号 J:パートナー組織 K:パートナー名 L:フリガナ M:所属 N:支局 O:自己級 P:L // ・旧形式 … A:リーダー番号 B:選手名 C:フリガナ D:パートナー番号 E:パートナー名 F:フリガナ G:所属 H:支局 I:自己級 J:L var isNew = s_(sh.getRange(1, 1).getValue()) === 'キャンセルフラグ'; var keyCol = isNew ? 'E:E' : 'A:A'; var hits = sh.getRange(keyCol).createTextFinder(key).matchEntireCell(true).findAll(); if (!hits || hits.length === 0) { return json_({ result: 'ok', found: false }); } // 同じ番号が複数行ある場合は、一番下（最新）の行を使う var row = 0; for (var i = 0; i < hits.length; i++) { if (hits[i].getRow() > row) row = hits[i].getRow(); } if (row < 2) return json_({ result: 'ok', found: false }); var v = sh.getRange(row, 1, 1, 16).getDisplayValues()[0]; var m; if (isNew) { m = { regLeader: s_(v[4]), leaderOrg: half_(v[5]), // リーダー組織（F列） leaderKanji: s_(v[6]), leaderKana: s_(v[7]), regPartner: s_(v[8]), partnerOrg: half_(v[9]), // パートナー組織（J列） partnerKanji: s_(v[10]), partnerKana: s_(v[11]), leaderSchool: s_(v[12]), // 所属（M列） branch: s_(v[13]), // 支局（N列） partnerSchool: '', gradeM: s_(v[14]), gradeL: s_(v[15]) }; } else { m = { regLeader: s_(v[0]), leaderOrg: '', leaderKanji: s_(v[1]), leaderKana: s_(v[2]), regPartner: s_(v[3]), partnerOrg: '', partnerKanji: s_(v[4]), partnerKana: s_(v[5]), leaderSchool: s_(v[6]), branch: s_(v[7]), partnerSchool: '', gradeM: s_(v[8]), gradeL: s_(v[9]) }; } return json_({ result: 'ok', found: true, member: m }); } catch (err) { return json_({ result: 'error', message: String(err && err.message ? err.message : err) }); } } /** * 申込内容の蓄積（電話番号0落ち対策：書式先設定 → 空欄appendRow → setValue上書き） */ function doPost(e) { try { var sheet = getEntrySheet_(); var data = JSON.parse(e.postData.contents); var phoneRaw = (data.phone || '').replace(/^'/, ''); var lastRow = sheet.getLastRow() + 1; // 電話番号（K列=11）の書式を先に文字列に設定 sheet.getRange(lastRow, 11).setNumberFormat('@'); var newRow = [ new Date().toLocaleString('ja-JP'), // A: 申込日時 data.regLeader || '', // B: 登録番号(L) data.regPartner || '', // C: 登録番号(P) data.leaderKanji || '', // D: リーダー data.leaderKana || '', // E: リーダーかな data.partnerKanji || '', // F: パートナー data.partnerKana || '', // G: パートナーかな data.leaderSchool || '', // H: リーダー所属教室 data.partnerSchool || '', // I: パートナー所属教室 data.address || '', // J: 住所 '', // K: 電話番号（後でsetValueで書く） data.events || '', // L: 出場区分 data.totalFee || '', // M: 合計金額 data.email || '', // N: メール data.transferDate || '', // O: 振込日 data.transferName || '', // P: 振込人名 data.transferAmount || '', // Q: 振込金額 data.branch || '', // R: 支局 data.leaderOrg || '', // S: リーダー所属団体 data.partnerOrg || '' // T: パートナー所属団体 ]; sheet.appendRow(newRow); sheet.getRange(lastRow, 11).setNumberFormat('@'); sheet.getRange(lastRow, 11).setValue(phoneRaw); return json_({ result: 'ok' }); } catch (err) { return json_({ result: 'error', message: String(err && err.message ? err.message : err) }); } }
